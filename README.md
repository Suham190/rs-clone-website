# RS Clone Website

## 📌 About the Project

**RS Clone Website** is a Facebook-inspired social media website clone that I created while following the Git and GitHub tutorial by **CodeWithHarry (Harry Bhai)**.

The main purpose of this project was to gain practical experience in web development and understand how to use Git and GitHub for managing and tracking code changes.

Through this project, I explored the basic structure of a social media website and learned how to organize project files, work with code, and manage a project using Git.

## 🎯 Project Objectives

- To practice the concepts of Git and GitHub.
- To understand how a website project is structured.
- To improve my basic web development skills.
- To gain hands-on experience by building a Facebook-inspired website.
- To learn how to track changes and manage code using Git.
